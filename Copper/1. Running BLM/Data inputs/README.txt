Directory: Spatial Assessment of Bioavailability Project > 
						1. Running BLM > 
							Data inputs

In this folder you will find the following files to be used accordingly:

	1. BLM_Data_Entry.html: knitted web-version of BLM_Data_Entry.Rmd 

	2. BLM_Data_Entry.Rmd: code developed to create the next 4 files using the WaDE_Synoptic_Summary.xlsx.
	
	3. BLM_Data_Entry_for_Zn.xlsx & BLM_Data_Entry_for_Cu.xlsx ready to be copied and pasted into BLM desktop
		
	4. WaDE_Synoptic_Summary_Clean.xlsx to be used in the 2. Dataset merging folder

	5. Omitted_Samples.xlsx: samples filtered out in BLM_Data_Entry.Rmd.

	4. BLM_manual.pdf: user guide and reference manual for running the Biotic Ligand Model VERSION 3.41.2.45 desktop.

	5. WaDE_Synoptic_Summary.xlsx: dataset from the East Fork Poplar Creek watershed containing all chemical analyses by sample and inherent properties of each site.
