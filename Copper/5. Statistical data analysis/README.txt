Directory: Spatial Assessment of Bioavailability Project > 
						5. Statistical analysis

In this folder you will find the following:

	1. Data_analysis.Rmd: code developed to statistically analyze the dataset called Bioavailability_Master_Spreadsheet_Clean_2.xlsx developed in the folder 4. Exploratory data analysis. It identified Typologies by only conducting a cluster analysis on flowing tributaries.

	2. Data_analysis.html: the knitted web-version of Data_analysis.Rmd.

	3. Bioavailability_Master_Spreadsheet_Clean_2.xlsx: created in Data_analysis.Rmd which includes the variable "Typology"

	4. Data_analysis_V2.Rmd: alternative code developed to statistically analyze the dataset called Bioavailability_Master_Spreadsheet_Clean_2.xlsx developed in the folder 4. Exploratory data analysis. It differs from Data_analysis.Rmd in that Typologies were defined by conducting a cluster analysis on all sites, not just flowing tributaries.

	5. Statistical_analyses_all_sites.xlsx, Statistical_analyses_by_typology.xlsx, and Statistical_analyses_flowing_tribs.xlsx: data outputs from Data_analysis.Rmd.

The following folders contain graphs and visuals created in the Data_analysis.Rmd file.
	- Plots of All Flowing Tribs (pre-Typology)
	- Plots of All Sites
	- Plots of Developed Tribs Typology
	- Plots of Flowing Tribs Typology
	- Plots of Main Stem Typology
