Sensitivity Analysis of Carbondate Assumption Zn BLM

Cecilia Albert-Black

Objectives

Two scenarios will be compared to conduct a sensitivity analysis of BLM’s carbonate system assumptions:

  • Baseline: Closed system, measured DIC as a BLM input variable

  • Perturbed: Open system, no DIC input. Instead, BLM estimates alkalinity by charge balance using pH and assuming in equilibrium with atmospheric partial pressure

5. Plots

Since the percent changes were not normally distributed, we’ll plot the median and inter quartile ranges (IQRs) for each variable

i. Percent change

library(dplyr)

# 1. Pivot table: turn columns into rows
long_percent_change_dic <- percent_change_dic %>%
  pivot_longer(cols = everything(),
               names_to = "Variable",
               values_to = "Value") %>%
  # Calculate the stats
  group_by(Variable) %>%
  summarize(
    median = median(Value, na.rm = TRUE),
    q1 = quantile(Value, 0.25, na.rm = TRUE),
    q3 = quantile(Value, 0.75, na.rm = TRUE)
  ) %>%
  # Sort variables by median value
  mutate(Variable = reorder(Variable, median))
  
  
# 2. Plot
library(ggplot2)

pc_plot <- ggplot(long_percent_change_dic, aes(y = Variable, x = median)) +
  geom_col(aes(fill = median)) +
  geom_errorbar(aes(xmin = q1, xmax = q3), width = 0.25) +
  geom_vline(xintercept = 0, linetype = "dashed", color = "grey40") +
  scale_fill_gradient2(
    low = "red3", mid = "grey95", high = "steelblue4", midpoint = 0) +
  labs(x = "Percent Change (Median ± IQR)", y = NULL, 
       title = "Percent Change Summary for Zn BLM",
       subtitle = "Closed system to open system BLM") +
  theme_bw() +
  theme(axis.text.y = element_text(size = 8)) + 
  guides(fill = "none")
