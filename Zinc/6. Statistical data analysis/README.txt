### Overview ###
This folder contains scripts and outputs for data analyses and plots for BLM run under baseline assumptions (HA 10% closed system) using the Bioavailability_Master_Spreadsheet_Clean3.xlsx dataset in the 5. Cluster analysis folder. 

This folder contains the code to run the analyses (Data_analysis_Zn_BLM.Rmd) and all of the output Excel files and plots.
